# Little Driver — Android prototype

2026-10-19 테스트 버전입니다. APK를 내려받아 ARM64 Android 8.0 이상 휴대폰에서 설치하세요.

1. LittleDriver-Android-2026-10-19.apk 파일을 다운로드합니다.
2. 다운로드한 APK를 열고, Android가 요청하면 사용한 브라우저/파일 앱의 설치를 허용합니다.
3. 가로 화면으로 실행하여 차량과 캐릭터를 고른 뒤 출발합니다.

- 휴대폰 기울기로 조향합니다. 1인칭에는 LEFT/RIGHT 버튼이 표시되지 않습니다.
- 왼쪽 기어 버튼을 누를 때마다 후진(R)과 전진(D)이 전환됩니다.
- 엑셀/브레이크는 길게 누르며, 별도 주차 브레이크로 정지 상태를 유지할 수 있습니다.
- 압력 감지를 지원하지 않는 기기에서는 페달 안의 터치 높이로 강도를 조절합니다.
- 실제 Android 기기에서 센서 방향, 동시 터치, 성능/발열 검증은 아직 진행하지 않았습니다.
- 기존 버전과 서명이 다르다는 오류가 발생하는 경우에만 기존 앱 제거 후 새로 설치하세요. 제거하면 기존 앱 저장 정보가 지워집니다.

이 저장소에는 공유용 APK만 배포하며 게임 소스는 포함하지 않습니다.
